## Description

This could be a big performance improvement and at very little functional cost.
I've very rarely benefitted from the automatic patching. The only way in which it benefits is as a debugging tool. KNowing that an iterator was invalidated can help debugging (but even that Ive rarely seen).
If we only 'patch' the iterator passed in to the remove call we probably get 50% of the benefit with none of the cost.
Note - teh cost is so high because even if you dont use the feature, you have to track linked list of owned iterators  which you must do cache breaking flush on accesses (cuz could go aacross threads).
