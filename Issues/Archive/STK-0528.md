## Description

wget http://www.nasm.us/pub/nasm/releasebuilds/2.12.02/nasm-2.12.02.tar.gz
tar xvf nasm-2.12.02.tar.gz
cd nasm*
sh configure
make
be sure nasm.exe in path of building openssl and change no-asm option to -asm
