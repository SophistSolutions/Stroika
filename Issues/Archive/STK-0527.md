## Description

I think there are two bugs - but they collaborate so that the net result is that (without a workaround) - curl doesnt support ssl.
First but - openssl 1.1 now depends on pthreads, but doesnt include lpthread in the resulting pkgconfig files. A workaround for this is to add -lpthread to the CONFIGURE line (I didnt bother since may not be right for all platforms just right for when using pthreads)
But also - the 'fix' I did include - because its needed - is to include in the libcurl makefile workaround - LIBS='-pthread'
