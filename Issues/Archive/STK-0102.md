## Description

Perhaps add Synchonized<SharedPtr<>> and Synchonized<shared_ptr<>>. 
That may simplfiy some ussage with the containers and iterables. But it may not be practical, since those APIs are intrinsically un-threadsafe. Thats probably the case/reason, in which case there needs to be some docs in Stroika to this effect.
