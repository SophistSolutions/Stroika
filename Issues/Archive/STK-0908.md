## Description

New Framework to embed python (and perhaps other languages) as extension languages
Mostly, this means following the instructions in https://docs.python.org/3/extending/embedding.html  and wrapping up an example. Maybe writing wrapper code to make integration a bit easier.
THis would be useful - for example - in WTF - so you could specify filters programatically (but would require careful sandboxing).
