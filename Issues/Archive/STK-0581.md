## Description

change

to 
FromObjectMapperType<T[SZ]> fromObjectMapper = [](const ObjectVariantMapper& mapper, const T fromObjOfTypeT[SZ]) -> VariantValue {
(and similar for to) - and lose the 'actualMember' stuff.
Just wnat to simplify - but doing this appears tricky to get to compile because as argument, the array is promoted to a pointer, which is not the same as an array, when filled into the function<> object.
