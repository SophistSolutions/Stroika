template <typename CONTAINER_OF_T, typename ENABLE_IF>
void MultiSet<T, TRAITS>::AddAll (const CONTAINER_OF_T& src)
{
for (auto i : src) {
Add ;
}
}
inline void Queue<T>::AddAllToTail (const CONTAINER_OF_T& s)
{
_SafeReadWriteRepAccessor<_IRep> tmp{this};
for (auto i : s) {
tmp._GetWriteableRep ().AddTail ;
}
}
Reason this is non-trivial is the arg to these addalls can be of differnt shape, handled by the Add overloading.
So must add an Add_ method taking a _SafeReadWriteRepAccessor and so parallel overloading.
Easy and probably modestly significant performance boost for relatively common case (cuz used in CTORs).
