## Description

Issue is that the the skel script creates a symbolic link to ../../ThirdPartyComponents/Stroika/StroikaRoot/Workspaces/VisualStudio.Net/Microsoft.Cpp.stroika.user.props and that file may or may not exist

Its imported with a line like 

```
    <Import Project="$(ProjectDir)\..\..\..\Workspaces\VisualStudio.net\Microsoft.Cpp.stroika.user.props" Condition="exists('$(ProjectDir)\..\..\..\Workspaces\VisualStudio.net\Microsoft.Cpp.stroika.user.props')" Label="User-Editable-Properties" />

```

whcih if the symbolic link exists, but the thing pointed to doesnt exist, erorrs out (due to IMHO a BAD design choice for interpretation of exist () function in project files when file referenced is symbolic link).

BUt I cannot change that choice. Sigh.
