## Description

Implement StdIStreamFromInputStream and StdOStreamFromOutputStream classes
Stroika has classes InputStreamFromStdIStream and OutputStreamFromStdOStream that make std::basic_inputstream/outoputstream objects work with Stroika streams.
Now we need the reverse!
