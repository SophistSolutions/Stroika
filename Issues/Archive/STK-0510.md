## Description

Its OK to checkout the code (unzip) to CURRENT in that (e.g. xerces/openssl) directory - so its easier to view/search the source code in a common place.
But DONT run configure - and probably not even PATCH there.
INSTEAD - COPY that data to IntermediateFiles/{CONFIG}/ThirdPartyCompoents/{EG-XERCES}/ instead of CURRENT and do the script stuff we do now in CURRENT there.
That way - in principle - it maybe possible to do diff configs in parallel (at least gets us closer).
And allows less duplicitive extract/patch when chagngin configs.
