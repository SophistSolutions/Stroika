## Description

EASY BIG PERFORMANCE FIX:
SET<>::EqualsReferenceImplematnion – calls Getlength… Don’t do that as it can be quite slow (length cound be expensive). That MIGHT make sense in a rep-specific thing – like set_array<> or something were we know both lhs/rhs types – but if not – in reference impl – just walk to iteraables and compare!!! Even thought that PROBALY means we have to iterate over BOTH lists and make sure both contain each other… actually- we’ve computed the length of one. It maybe cheaper after we’ve completed the first iteration, before computing the second – to see if the lemngths match…
