## Description

Either add optional --merge argument, or always do merge functionality.

If merging, and you detect a folder that already exists, DONT create (but warn).
And for file that would have been created - INSTEAD create THATFILE.SKEL_ADDITION and warn so user can hand merge.
That way - you could go into an existing project like HealthFrame, and use Skel to add missing files or drafts of files to get merged. And you can have multiple apps in a single large app (like WTF/Backend, WTF/SomeUtil).
