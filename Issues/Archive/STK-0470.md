## Description

Very hard bug I ran into with AIX, with stack overflow, triggered by a larger stack buffer in InputStream::ReadAll<byte> (I think).
Appears no standard way to ask total thread size or set total thread size, or total stack left. But all of these might be helpful.
Probably best thing todo is to provide API with STATIC DEFAULT (optional), and individual thread parametner (again optional). Use to specify stack on startup (just as part of creation).
Existing std::thread stack practice on differnt systems:
Windows: calls _beginthreadex (stacksize=0) - which means use the default.
https://msdn.microsoft.com/en-us/library/windows/desktop/ms686774%28v=vs.85%29.aspx?f=255&MSPPError=-2147217396
he default size for the reserved and initially committed stack memory is specified in the executable file header. Thread or fiber creation fails if there is not enough memory to reserve or commit the number of bytes requested. The default stack reservation size used by the linker is 1 MB. To specify a different default stack reservation size for all threads and fibers, use the STACKSIZE statement in the module definition (.def) file. Not super easy to find stack size - but apparently you can somehow get tlb?? and from there get bacse and end of stack (so full size).
GCC:
Consider adding -fstack-protector or -fstack-protector-all to default gcc options for apply-debug-options. Verify that would have found the problme I an into with AIX.

another HINT on windows side - to detect stack size and usage:
public static class StackManagement
{
[StructLayout(LayoutKind.Sequential)]
struct MEMORY_BASIC_INFORMATION
{
public UIntPtr BaseAddress;
public UIntPtr AllocationBase;
public uint AllocationProtect;
public UIntPtr RegionSize;
public uint State;
public uint Protect;
public uint Type;
};
private const long STACK_RESERVED_SPACE = 4096 * 16;
public unsafe static bool CheckForSufficientStack(UInt64 bytes)
{
MEMORY_BASIC_INFORMATION stackInfo = new MEMORY_BASIC_INFORMATION();
UIntPtr currentAddr = new UIntPtr(&stackInfo);
VirtualQuery(currentAddr, ref stackInfo, sizeof(MEMORY_BASIC_INFORMATION));
UInt64 stackBytesLeft = currentAddr.ToUInt64() - stackInfo.AllocationBase.ToUInt64();
return stackBytesLeft > (bytes + STACK_RESERVED_SPACE);
}
[DllImport("kernel32.dll")]
private static extern int VirtualQuery(UIntPtr lpAddress, ref MEMORY_BASIC_INFORMATION lpBuffer, int dwLength);
}
