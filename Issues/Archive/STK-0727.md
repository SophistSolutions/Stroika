## Description

https://tools.ietf.org/html/rfc2616#section-3.6.1
https://tools.ietf.org/html/rfc2616#section-14.40
etc..
Fairly easy.
  - must add property to Response called 'trailers' which is a set of headers not to be sent initially.
  - then ALLOW updates to all the headers in the trailers section (currently have asserts no) (cannot disable asserts perfectly but good enuf)
  - then if set, send trailers andHEAD and actual trailuers (trailers would be a properity of http::Headers).
There are lots of details abotu making this work correctly (including accept-trailers or some such).
Seems a real corner case and probably not worth doing anytime soon (especailly as http 2.0 has a differnet mechanism.
