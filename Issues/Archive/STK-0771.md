## Description

USE THIS FOR WINDOWS TOO TO CREATE INSTALLER WITH x86 and x86_64 binaries in same installer
Ø New configuration option PACKAGE_ONLY, which skips library, TPP, etc, and only builds samples/tests/runtests
Ø New build rule like linker to FatPackage – with new configuration whihci is list of base configurations (from each can figure architecture)- PACKAGE_BASED_ON=
Ø Then generic rule to do the package (using lipo link above)
Ø Probably set stuff like COMPILER flags etc all to EMPTY or MISSING from config in PACKAGEONLY configuration

Applies for windows installers (x86 and 64) and for macos. Not sure if unix installers (rpm/deb) support this idea?
