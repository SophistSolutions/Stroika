## Description

Create a new ‘framework’ making it easy to wrap Stroika apps in a web browser (as it is with qt).
Probably use 
     https://github.com/chromium/chromium 
     https://github.com/chromiumembedded 

Goal is to be able to easily wrap WTF as a thick app on a cell phone, or mac, or whatever, and similarly basic for rewrite of HeathFrame (perhaps) using this.
