## Description

use lock in mem-initializer.
It has exactly the right sematnics - using an unnamed temporary (lifetime ends at end of full expression and value of , is last item).
But issue is that for constexpr functions - the lock crap violates the constexpr rules (at least msvc 2k17).
Not super importnat cuz doesnt affect correctness, but nice to fix so we get better debug race checking.
