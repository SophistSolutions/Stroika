## Description

I've long intended to do an implementation Set_BitString<> (or Sequence_BItString).
But talking to Tom (Tom Pringle) about a problem he's working on, I realized this could be pretty easily used to store arbitrary (fixed) sized objects.
So for example, 
template <typename T, size_t nBits, typename BaseType=std:::byte>
class Sequence_PackedBits : Sequence<BaseType> {
};
// like vector, except packs at the bit level, so Sequence_PackedBits <T, 4> would act like a regular Sequence<T>, but would use 1/2 the space of Sequence_vector<>;
I guess this doesn't make sense for Set ... there we really just would use Set_BitString<> - because the index is the number stored in the set, and it only makes sense to use 1 bit there cuz the only relevant property is contains or not.
You COULD use this PackedBits trick for MultiSet<T> however.  MultiSet_PackedBits, could be implemented as an array of nbits per element of how many are in the multiset.
