### Lewis Pringle - 2017-10-05T12:32:21.081-0400

http://en.cppreference.com/w/cpp/thread/condition_variable/notify_all says:
The notifying thread does not need to hold the lock on the same mutex as the one held by the waiting thread(s); in fact doing so is a pessimization, since the notified thread would immediately block again, waiting for the notifying thread to release the lock.

### Lewis Pringle - 2017-10-13T18:31:15.834-0400

added helgrind suppression and documented the reasons for this approach (pessimization avoidance)
