## Description

The fact that InsertAt is a const method and Append() is non-const is clearly deeply confusing.
Best to relplace 
Current Mutating methods (as of v3.0d1x)
     *          o   SetCharAt
     *          o   c_str()
     *          o   operator=
     *          o   clear()
     *          o   Append
     *          o   operator+=
     *          o   c_str ()  -- non-const
     *          o   erase()
mark as deprecated, and some gone.
Then can say clearly - all string apis non-const.
Biggest/only challenge, is non-const c_str() which is very handy for printing stuff (debug messages) - but maybe avoided/fixed by new String format stuff, so maybe wait on that to decide (or maybe do all but c_str() til we decide about that).
