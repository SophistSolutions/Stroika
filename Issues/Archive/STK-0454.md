## Description

Add feature to replace (but typically and maybe only) append to OpenSSL (and curl etc) configure lines.
SOme of the hardwired stuff we have in the makefile can then be moved to the build configure script.
And more importantly - users can edit that configure rather than having to use some other mecnaiums to enable certain features.
