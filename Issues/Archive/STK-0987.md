## Description

ThreadPool feature – WARN if thread runs longer than XXX. Or maybe debug method that returns how long each task has been running. And then use IntervalTask manager to print dbg message once a minute with a summary of anything over a minute.
This would be handy to debug cases of tasks spun off in webserver that are taking too long.
