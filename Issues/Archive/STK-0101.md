## Description

	String EVEN WITH all my fixes to String thread safety, what if you have
o	Global
	String x;
o	Thread 1
	Use (x.c_str ())
o	Thread 2:
	X = L”x”;
Use of c_str() or As<Character*> () or As<wchar_t>() instrunisically unsafe IF you use a String object from multiple threads – and overwrite it WHILE calling x.c_str()
COULD have changed String::x_str() to return proxy object to bump refcount, BUT that woudlnt work with uses through (…) – like Format() – which is probably 99% of uses, so not a good idea.
(OR - COULD return proxy object but hiding simpler)
